# Prism Mail Web (PWA)

Privacy-first multi-provider email hub — Vite + TypeScript PWA (offline service worker, Vitest, Playwright, Lighthouse CI). Brand kit: [`branding/BRANDING.md`](../../branding/BRANDING.md).

## Chrome

Home is **Settings-only**. Theme, About, and donate live under Settings → App info — never in the header.

## Dev

```bash
npm ci
npm test
npm run build

```
